- WAF is not automatic on Cloudfront distributions, you need to enable it (will show up in Security tab if enabled)
- If Confluence says an RFC takes 25min to read; it probably takes over a day to actually review and understand
- CSRF protection is disabled by default in Rails tests
- You can't call `form_authenticity_token` in tests (even by using `send` on the controller), so you need to extract it from HTML
  - which requires making a `GET` request so you have HTML to extract it from
