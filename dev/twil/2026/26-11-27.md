- If Neovim's rubocop isn't working, try `bundle exec rubocop --stop-server` then `bundle exec rubocop --no-server` to unstick it
  - Apparently can be caused by Mason's rubocop running first, leading to the Gemfile's rubocop not running
- `git rebase --onto $delete_after_this $last_to_delete`
- Javascript's `encodeURI` & `encodeURIComponent` encode different things
  - For example, `encodeURI` won't encode `#` because it's the fragment indicator, even if it's partway through the query string
  - So you need to run `encodeURIComponent` on just the query string, or more specifically the value
  - Since that one will encode `?` and `=` as well
- `%()` creates a `""`-like string literal, but allows having `""` inside it
